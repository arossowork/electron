# TPS610994 (TI TPS61099x family), datasheet SLVSD88M (Aug 2026), https://www.ti.com/lit/gpn/tps61099

Read in full pages 1-6 (features, device table, pins, abs max, electrical). Orderable fixed 3.3 V part: TPS610994YFFR (DSBGA-6, YFF0006, 1.23 x 0.88 mm, 0.4 mm pitch). The DRV (WSON-6) package is listed in the datasheet for the family but TPS610994DRVR is not stocked at DigiKey, Mouser or LCSC. KiCad has `Regulator_Switching:TPS610994DRV` (WSON pins); this project uses its own symbol `thermostat:TPS610994YFF` with ball names.

Facts the design needs:
- Tie EN to VIN (always on) and FB to GND.
- COUT is specified 10-100 uF. The design adds 4.7 mF at the rail, 47 times the specified maximum. Start-up charging current is limited to 0.5-0.75 A below 2.5 V (4.7 mF x 2.5 V / 0.5 A = 24 ms). Stability with 4.7 mF is not covered by the datasheet. Keep the 10 uF ceramic at the pin and put the 4.7 mF behind it, and check the output ripple at bring-up. Risk R-TPS-1.
- Peak switch limit 0.8 A min. Average input current limit is about 0.8 - 0.3/2 = 0.65 A (min) and 1.0 - 0.15 = 0.85 A (typ).
- The SPICE model supplied by TI for this family is an encrypted PSpice model, which ngspice cannot read. The project uses `models/tps610994_avg.lib` (behavioral, source: behavioral).

## Stage 3 re-check (iteration 3): SLVSD88M pp. 12-16 read

- 7.3.8 (p.12, fig. 7-3 p.13): down mode starts when VIN > VOUT - 50 mV (PMOS gate pulled to ground; the PMOS drop regulates VOUT at target, losses rise); down mode continues until VIN > VOUT + 0.5 V (3.8 V for 3.3 V), then automatic PASS-THROUGH (PMOS fully on, low-side switch off, VOUT = VIN minus inductor DCR and PMOS Ron drops). Exit: back to down mode when VIN falls to 103 % of target (3.40 V); down mode until VIN is 100 mV below VOUT (3.2 V), then boost. The 50 mV, 0.5 V, 3 % and 100 mV values carry no min/max.
- 7.3.5 (p.12): current limit still cycle by cycle in down mode; NOT enabled in pass-through. Below VOUT 1.6 V the device re-enters start-up (200 mA limit, 7.3.6). A 3.6 V lithium pack (2 x 1.8 V) is 0.2 V below the pass-through entry, so the rail stays regulated.
- p.16: nominal minimum output capacitor 20 uF. Table 8-2 inductors for VOUT > 3.0 V: 2.2 uH Wuerth 74404024022 (1.95 A, 80 mOhm), muRata LQH2HPN2R2MJR (1.7 A, 92 mOhm), TDK VLS201610 (1.45 A). L1 (Chilisin 1.9 A, 80 mOhm) is equivalent to the first.
- SPICE: vendor model is encrypted PSpice (unchanged); project model `models/tps610994_avg.lib` (behavioral).
