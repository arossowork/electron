## Consequences for this design
- Pin map and wiring (REFIN = AVDD_SW, REFOUT NC, AINN1/AINN2 = GND, PGA 1) match the datasheet. No schematic change.
- Common mode with AINN at GND is legal only at PGA 1/2 (AGND - 0.1 V min). PGA 1 is mandatory.
- Full scale at PGA 1 is +/-0.5 VREF: the node ratio Rntc / (47 k + Rntc) must stay below 0.5, i.e. Rntc < 47 k, i.e. T > -6.2 C (B 3950: 47 k = 10 k x exp(3950 (1/T - 1/298.15))). Operating range is 0-50 C (ratio 0.417 at 0 C), so this holds. Below -6 C, and with an open probe, the code saturates at 0x7FFFFF: firmware treats a saturated code as "probe fault or below -6 C".
- AVDD_SW is switched off between measurements, so the chip goes through power-on reset at every wake and comes up with PGA 128, 10 Hz, REFOUT on. Firmware writes the config register (0x65) at every wake before the first conversion: 0x70 (REFO_OFF 1, 1280 Hz, PGA 1, channel A), 0x71 (channel B), 0x73 (internal short, offset). Discard the first 4 conversions after power-on and after each channel switch (2.6.1); 4 / 1280 Hz = 3.1 ms.
- Operating current 1.26 mA typ is below the 1.5 mA the architecture assumed, so the measurement energy (R2) is conservative.
- Gain error: ratiometric measurement cancels VREF changes but not the converter's own gain error. The datasheet gives +/-0.5 % (typ, PGA 128) and nothing at PGA 1. The architecture error budget (section on R4) counted the gain as "cancels", which is wrong. At +/-0.5 %: 35 C node 0.401 V x 0.5 % = 2.0 mV / 14.66 mV/K = 0.137 C; 5 C node 1.173 V x 0.5 % = 5.9 mV / 38.6 mV/K = 0.152 C. The worst-case sums become 0.58 C (35 C) and 0.63 C (5 C), over the +/-0.5 C of R4. Fix (lead decision, no cost or spec change): one-point gain calibration per unit at bring-up with a 10.00 k 0.1 % resistor in place of each probe at J2, stored in flash. Residual: 0.1 % resistor -> 0.024 C at 25 C (same sensitivity term as Rtop), plus gain drift 8 ppm/C x 25 C = 0.02 % -> < 0.01 C.
