# SPICE models (stage 4)

All project models are in `models/thermo.lib`. No vendor model is used: no vendor model was obtained for the MAX17227A (an ADI LTspice model was not looked for; the TPS61299 it replaced on 2026-10-22 had TI PSpice models that could not be downloaded), the DRV8837 model (SLVM958A) could not be downloaded, and no models exist for the others. Every active part is therefore approximate. The table says why each model is enough for the measures that use it.
