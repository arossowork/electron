# nRF9151 (Nordic) facts, nRF9151 PS v1.0 features pages (DigiKey copy mm.digikey.com/.../NRF9151-DK.pdf)
- Supply 3.0-5.5 V single supply (VDD). DevZone 121357: user reports HW design guide asks > 3.2 V; Thingy:91 X runs VDD from 3.2-5.0 V. Design floor 3.2 V (to confirm in nwp_056 at stage 3).
- PSM floor 2.7 uA @ 3.7 V; eDRX 81.92 s: 18 uA Cat-M1, 32 uA Cat-NB1 (UICC included), @ 3.7 V.
- Power class 3 23 dBm, class 5 20 dBm. Cat-M1 bands incl. B3, B8, B20; NB1/NB2 incl. B3, B8, B20. PSM, eDRX, DRX.
- GNSS: GPS L1 C/A + QZSS only (no Galileo) -> IF-3 needs an external receiver.
- Cortex-M33, 1 MB flash, 256 kB RAM, 12-bit SAADC 8 ch, 32 GPIO, SWD. SIM and eSIM (ETSI TS 102 221 UICC).
- LGA 12.1 x 11.1 x 1.2 mm. -40..85 C.
- Price: LCSC C22397843 16.24 USD @1 (out of stock 2026-10); Symmetry 13.75 @1000; Newark 15.76 @1000.
- TX peak current: not in the brief PS pages; PWR-4 keeps 0.5 A / 2 ms (lead default); confirm at stage 3.

## Stage 3 additions (partial: the PS pin table and nwp_056 HW guide were NOT readable; mouser.com PS pdf blocks curl, docs.nordicsemi.com pages 404 for fetch)
- DevZone 128776: DEC0 decoupling must be 4.7 uF (internal regulator, ~2.2 V), do not change. DevZone 126378: VDD 3.0-5.5 V, VDD_GPIO 1.7-3.6 V, apply VDD before VDD_GPIO, remove VDD_GPIO first; VDD_GPIO low while ENABLE low. nRESET: internal reset circuit, external parts only for noise decoupling (nwp_056). AUX pin may float. COEX0-2 driven by modem.
- DevZone 117789 (Nordic): a passive-only GPS antenna is not recommended for the SiP's own GNSS (we use LC76G, so n/a).
- Open for the circuit stage: LGA pin names/numbers (PS section 11.1.1), VDD cap values (reference: 4.7 uF + 100 nF class, unverified), LFXO need (SiP has the 32 kHz clock inside per product brief; NOT confirmed in text: assume none and verify nwp_056), SIM pins (SIM_CLK/RST/IO + SIM supply), antenna pad ANT. No KiCad symbol or footprint: project library.
- Certification: Nordic markets the SiP as "certified for global operation" (DigiKey highlight). It is a SiP with RF-ready ANT pad: the SiP carries Nordic's modem certification (GCF/PTCRB/carrier) but the END PRODUCT still needs RED testing (EN 301 908-13 + -25, EN 303 413 for GNSS, EN 62368, EN 301 489) with our antenna. No third-party pre-certified nRF9151 module was found (search 2026-10).
