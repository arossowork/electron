# RP2040 (Raspberry Pi) facts for the keyboard MCU

Source: RP2040 Datasheet build RP-008371-DS-1, https://pip-assets.raspberrypi.com/categories/814-rp2040/documents/RP-008371-DS-1-rp2040-datasheet.pdf (642 PDF pages, PDF page = printed page + 1; read as images).

## Current at 48 MHz with USB (sec. 5.7.2, Table 637, printed p.623)
Software use-case "BOOTSEL mode" (clk_sys 48 MHz, USB mass-storage active, host Raspberry Pi 4):
| state | DVDD typ / max mA | IOVDD typ / max | USB_VDD typ / max | sum typ / max |
|---|---|---|---|---|
| BOOTSEL active (USB traffic) | 9.4 / 14.7 | 1.2 / 4.3 | 1.4 / 2.0 | 12.0 / 21.0 mA |
| BOOTSEL idle (USB connected, no traffic) | 9.0 / 14.3 | 1.2 / 4.3 | 0.2 / 0.6 | 10.4 / 19.2 mA |
| Sleep (hello_sleep) | 0.39 / 4.5 | - | - | ~0.4 mA + USB PHY |
| Dormant | 0.18 / 4.2 | - | - | - |
DVDD is made by the on-chip linear regulator from VREG_VIN, so the 3.3 V rail supplies DVDD + IOVDD + USB_VDD current: ~12 mA typ, ~21 mA max (BOOTSEL numbers include the XIP flash running the ROM boot code; QMK scanning at 48 MHz with WFI sleeps in between is in the same range or lower). Peripheral baseline (Table 635, printed p.622): XIP 37.6 uA/MHz, IO + pads 23.6 uA/MHz, USBCTRL 1.3 uA/MHz (Table 636). Figure 172 (p.624): DVDD both cores running FFT, ~12-14 mA at 48 MHz, ~30 mA at 125 MHz.
From 5 V through the 3V3_D buck at ~88 %: 12 mA x 3.3 / 5 / 0.88 = 9 mA typ, 16 mA at the maximum. The earlier 6-8 mA class estimate was low; use 9 mA typ (5 V-equivalent), 16 mA max, plus the W25Q16JV flash read current (not part of the BOOTSEL figure only if it is idle: add 2-4 mA).

## Supplies (sec. 5.6, Table 634, printed p.622)
IOVDD 1.62-3.63 V, DVDD 1.05-1.16 V (typ 1.1), VREG_VIN 1.62-3.63 V, USB_VDD 3.135-3.63 V, ADC_AVDD 1.62-3.63 V.

## Crystal (sec. 2.16.1.1, Table 257, printed p.216)
RP2040 supports 1-15 MHz crystals; reference design uses 12 MHz. Recommended Abracon ABM8-272-T3: 12.000 MHz, fundamental AT, tolerance +-30 ppm, ESR max 50 ohm, C0 max 3 pF, load capacitance CL = 10 pF, drive level 10 uW typ / 200 uW max. The oscillator is powered from IOVDD (tuned for 3.3 V). Reference design: 1 k damping resistor in XOUT, 15 pF to GND on XIN and XOUT (Pico). A different crystal needs a stability test over temperature (datasheet p.217).
Chosen crystal JSCJ CJ13-120001210B20 (LCSC C2875246): 12 MHz, CL = 12 pF, +-10 ppm / +-20 ppm (LCSC page). Load caps: CL = C1 C2 / (C1 + C2) + Cstray, Cstray ~ 3 pF  ->  C1 = C2 = 18 pF (9 + 3 = 12 pF). Keep 1 k in XOUT. ESR/drive level of the CJ13 not read: confirm that its ESR <= 50 ohm.

## Typical use of GPIO
30 GPIO (GPIO0-29), GPIO26-29 are the ADC pins (ADC_AVDD must be powered anyway). QSPI (6 pins), USB D+/D-, SWD, RUN, XIN/XOUT are separate pins.
