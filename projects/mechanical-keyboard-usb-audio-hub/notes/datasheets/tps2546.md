# TPS2546 (TI, dual-ILIM USB charging port controller + 73 mohm switch) - facts
Source: https://www.ti.com/lit/ds/symlink/tps2546.pdf (via text proxy)
- VIN 4.5-5.5 V, abs max 7 V (p4). Rds_on 73 mohm typ, 120 max (p6). 16-pin WQFN 3x3 (p3).
- Pins: 1 IN, 2 DM_OUT, 3 DP_OUT, 4 ILIM_SEL, 5 EN, 6-8 CTL1-3, 9 STATUS, 10 DM_IN, 11 DP_IN, 12 OUT, 13 FAULT, 14 GND, 15 ILIM_LO, 16 ILIM_HI (+ thermal pad). (verify with lib pads)
- Current limit (p31-32 eq. 1-3): Ios_typ(mA) = 50250 / R(kohm); MAX = 1.0139 x 50250 / R + 30; MIN = 45271 / R^0.98437 - 30.
  R range 16.9-750 kohm. CORRECTED 2026-10-23 (stage 5 review M2): the earlier line had the +-30 mA offsets with
  the wrong signs (max "-30", min "+30") and the 0.98437 as a factor instead of an exponent; that made every
  minimum look 60 mA too high. The corrected forms reproduce the review figures: 562 k -> 59 / 89 / 121 mA,
  199 k -> 217 / 253 / 286 mA (review: 288; the max form is the less certain one, re-read p32 before release; this
  session could not open the PDF). Design values (stage 5): 464 k -> 77 / 108 / 140 mA; 188 k (464 || 316) ->
  231 / 267 / 301 mA; 87.9 k (464 || 316 || 165) -> 523 / 572 / 610 mA; ILIM_HI 28.0 k -> 1673 / 1795 / 1850 mA.
  Examples: 80.6 k -> 625 mA, 16.9 k -> 2970 mA, 210 k -> 240 mA (p6). ILIM_SEL (and CTL pins) choose ILIM_HI or ILIM_LO.
  The -30 mA offset of the minimum sets the lowest guaranteed floor: 75 mA min needs R <= 475 k (typ >= 106 mA).
  Only two resistor banks (HI/LO) per chip: 3 bus-mode values + 1.7 A need an external switched resistor (NFET parallel R on ILIM_LO).
- Iq: disabled 0.1-2 uA; enabled SDP 165-220 uA; DCP auto 175-230 uA (p6). FAULT/STATUS open-drain (p3, p7).
- BC1.2: SDP (500/900 mA), CDP (1.5 A min, data pass-through), DCP (1.5 A, shorted/divider/1.2 V) selected by CTL1-3 (Table 3, p28). 1111 = CDP ILIM_HI, 0011 = DCP auto.
- No SPICE model in the datasheet.
- KiCad: no symbol (project symbol needed). Footprint: Package_DFN_QFN:WQFN-16-1EP_3x3mm_P0.5mm_EP1.68x1.68mm or Texas_RTE_WQFN-16-1EP_3x3mm_P0.5mm_EP1.2x0.8mm (RTE package -> use the Texas_RTE one).
