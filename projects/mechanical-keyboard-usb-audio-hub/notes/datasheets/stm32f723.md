## Recalled [M]
- 216 MHz Cortex-M7, 512 KB flash, 256 KB RAM, 1.7-3.6 V; USB 2.0 OTG HS with on-chip HS PHY (F723 differs from F722 only here); 2 x SAI, 4 x I2S.
- Current (3.3 V, 25 C): run mode at ~108 MHz with ART on about 35-45 mA, plus HS PHY and USB ~10 mA, so budget 55 typ / 70 worst mA at 3.3 V.
- HS PHY clock comes from the HSE crystal (the F723E-Discovery uses 25 MHz HSE); REXTPHYHS needs one external resistor to ground (value: read the datasheet) ; V12PHYHS decoupling capacitor.
- TinyUSB has an STM32F7 UAC2 port; an F723-based USB-I2S board (768 kHz / 32 bit play + record, 2 ch) is documented on diyaudio [S].

## Clock plan (circuit stage)
DAC ES9039Q2M is the **I2S master** (BCLK on DATA_CLK pin 12, WS on DATA1 pin 13) from the low-jitter oscillator on MCLK (pin 32); STM32 SAI1_A (TX) is a slave, SAI1_B (RX, from the ADC) is synchronous with A; ES9822PRO is an I2S slave on the same BCLK/WS and takes the same MCLK on ACLK. USB feedback (async, explicit) from a timer that counts the DAC frame clock per SOF. No audio clock is generated by the MCU, so MCU jitter does not reach the converters.
I2C1 from the STM32 configures the DAC (0x90..0x96) and the ADC.

## Rails
3V3_D only (VDD, VDDA via ferrite/RC, VDDPHYHS 3.3 V, V12PHYHS and VCAP via capacitors). No 0.9 V, no 1.8 V.
