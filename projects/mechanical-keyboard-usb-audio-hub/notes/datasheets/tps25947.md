# TPS25947 (TI eFuse, 2.7-23 V) - facts
Source: https://www.ti.com/lit/ds/symlink/tps25947.pdf (SLVSFC9, via text proxy, first 100k chars)
- VIN 2.7-23 V, abs max 28 V, -15 V reverse; Vout abs max min(28, Vin+21) (p7-8). Ron 28.3 mohm typ (p1); ~45 mohm worst case.
- Current limit: R_ILM(ohm) = 3334 / ILIM(A) (p30); range ~0.5-6 A (p9); accuracy +-10 % only for ILIM > 1 A (p1) -> a 0.8 A nominal trip is outside the specified accuracy (risk for trip <= 0.9 A).
- Reverse current blocking / linear ORing, Vfwd ~4.7-16.9 mV, reverse leakage 10.1 uA at Vout-Vin 21.5 V (p10). Iq 426-610 uA normal, 193 uA in RCB (p9); disabled 73-130 uA, shutdown 4.4-28.7 uA (p9).
- UVLO/EN 1.20 V rising / 1.09 falling (p9). Package QFN 2x2 mm, 0.45 mm pitch, 10 pin (RPW) (p1, p3) - hard to escape on a 4-layer JLC board.
- ILIM switching 0.9/1.5/3.0 A: parallel resistor via small NFETs on ILIM pin (R_ILM 4.17 k / 2.47 k / 1.24 k for 0.8/1.35/2.7 A nominal).
- No SPICE in datasheet. KiCad symbol: none (TPS2592xx exists but is a different part).
