# Import graph of `hwflow`

Generated by `uv run python scripts/import_graph.py` (AST scan of `src/hwflow`, 34 modules). Re-run it after a refactor.

## Result

- **No import-time cycle.** Considering only module-level imports, the graph is acyclic.
- All cycles go through **lazy imports** (inside a function body), which the code uses to break the loops at import time.
- Counting lazy imports too, there are two strongly connected groups:
  - Big group (18 modules): asicflow, barrier, blocks, budgets, corridor, design, feasibility, floorplan, gplace, keepout, kicad, libs, pcb, pinaccess, placer, postlayout, seedroute, spice.
  - Small group: diagnose <-> partescape.

Direct two-way pairs (`top` = module-level import, `lazy` = function-level):

| pair | direction types |
|---|---|
| pcb <-> placer | pcb top, placer lazy |
| design <-> pcb | design lazy, pcb top |
| design <-> placer | design lazy, placer top |
| design <-> spice | design lazy, spice top |
| design <-> floorplan | both lazy |
| postlayout <-> budgets | both lazy |
| corridor <-> pcb | corridor top, pcb lazy |
| pcb <-> seedroute | both lazy |
| blocks <-> placer | blocks top, placer lazy |
| blocks <-> design, libs, pcb | both lazy |
| keepout <-> placer | keepout top, placer lazy |
| floorplan <-> pcb, placer | both lazy |
| asicflow <-> gplace, pcb, placer | both lazy |
| diagnose <-> partescape | both lazy |

The issue's list (pcb<->placer, postlayout<->budgets, corridor<->barrier<->seedroute, design->layout) matches in
substance: pcb<->placer and postlayout<->budgets are confirmed. corridor/barrier/seedroute sit in the big group
(corridor<->pcb<->seedroute) rather than as a direct three-cycle. There is no `layout` module; `design` is entangled with
`pcb`, `placer`, `spice` and `floorplan`.

## Guardrails (import-linter, `uv run lint-imports`)

Contracts in `pyproject.toml` describe what is true today and pass:

1. `hwflow` imports nothing from `harness`, `ui` or `evals`.
2. The engine modules (design, pcb, placer, spice, sch, kicad, sexpr) do not import `hwflow.cli`.

No contract forbids the cycles above yet; tightening comes with the refactors that remove them.

## CI

`.github/workflows/ci.yml`: `lint` (ruff, lint-imports) and `test` (`pytest -m "not slow"`, with KiCad 10 and ngspice
installed on the runner) on push and pull request to main. The nightly `slow` job runs `pytest -m slow`; the router
(`tools/KiCadRoutingTools`) and Freerouting are not on the runner, so tests needing them skip, and "no tests ran" (exit
5) is not a failure. `scripts/pre-commit` runs the same fast tier locally.
